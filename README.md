<h1 align="center">🎓 Result Management System</h1>
<p align="center">
  A desktop application to manage student results, built with <strong>Python (Tkinter)</strong> and <strong>MySQL</strong>.
</p>

<hr>

<h2>✨ Features</h2>
<ul>
  <li>📝 Student registration with clean UI</li>
  <li>📊 Marks entry with <strong>automated grade calculation</strong></li>
  <li>📄 Result generation with printable reports</li>
  <li>✅ Input validation and error handling</li>
  <li>🔍 Search, ✏️ Update, ❌ Delete student records</li>
  <li>🗄️ Uses <strong>MySQL</strong> for fast and reliable data storage</li>
</ul>

<h2>🚀 Getting Started</h2>
<h4>Prerequisites:</h4>
<ul>
  <li>Python 3.x</li>
  <li>MySQL Server</li>
  <li>MySQL Connector for Python</li>
</ul>

<h4>Installation:</h4>
<ol>
  <li>Clone or download this repository.</li>
  <li>Set up your MySQL database using the included SQL script.</li>
  <li>Install required Python packages:
    <pre><code>pip install mysql-connector-python</code></pre>
  </li>
  <li>Run the app:
    <pre><code>python dashboard.py</code></pre>
  </li>
</ol>
